# Vapor for Firefox

This setup applies the complete Vapor appearance: matching colors, controls
styled to look closer to KDE Breeze, and matching normal and private windows.
The Breeze-style appearance is included by default.

## Apply the theme

1. Extract the downloaded ZIP file to a folder.
2. Open **Apply Vapor to Firefox** in that folder. Choose **Execute** if your
   file manager asks how to open it.
3. Choose **Apply Vapor to Firefox** in the setup window.
4. Follow the instructions to find Firefox's settings folder. Firefox can show
   you this folder from **Menu > Help > More Troubleshooting Information >
   Profile Directory > Open Directory**.
5. Close all Firefox windows, then select that settings folder in the setup
   window. This makes sure Firefox has finished saving your settings.
6. Open Firefox again.

You do not need to log out of KDE Plasma. The setup keeps your existing browser
settings and adds the files needed for the appearance. It does not change your
bookmarks, passwords or browsing history.

## Private windows

Private windows use Vapor colors and Breeze-style controls too. The private
start page also gets a matching background. Firefox's private-browsing badge
and its messages remain visible so you can recognize a private window.

## Remove the theme

Open **Apply Vapor to Firefox** again and choose **Remove Vapor from Firefox**.
Close Firefox and select the same settings folder when asked, then open
Firefox again. Your other settings and custom appearance files are kept.

This appearance uses Firefox's custom-style support. Firefox updates can
change how it looks; this first build is checked against Firefox 159 on Linux.
It is a community theme, with no change to how private browsing protects data.
