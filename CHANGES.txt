SteamOS Vapor/VGUI KDE theme, fixed for Plasma 6.8
Based on steamdeck-kde-presets 3.9.4-2 (original package in ../steamos), theme files only.
Made 2026-10-29, audited against Plasma 6.8.2 / Qt 6.12 / GTK 3.24.

Fixes:
- com.valve.vgui.desktop splash: Splash.qml replaced with the Vapor Deck one
  (same file except it uses Kirigami.Units instead of Plasma 5's PlasmaCore.Units,
  which no longer exists, so the spinner and fade-in were broken).
- All three global themes, contents/defaults:
  - removed [kwinrc][WindowSwitcher] LayoutName=org.kde.breeze.desktop
    (that switcher was removed in Plasma 6; applying the theme overwrote your
    Alt+Tab choice with it and KWin fell back to Thumbnail Grid)
  - removed [kwinrc][DesktopSwitcher] (feature removed in Plasma 6)
  - removed [KSplash] Theme=com.valve.vapor (wrong section and ID, never read)

Improvements:
- Vapor GTK theme (gtk-3.20/gtk.css): removed three style properties GTK 3.24
  rejects (-GtkButton-child-displacement-x/-y, -GtkScrolledWindow-scrollbars-within-bevel),
  so GTK 3 apps no longer print three warnings at startup. No visual change.
- Wallpaper: "Steam Deck Logo Default.jpg" is now a Plasma wallpaper package,
  wallpapers/SteamDeckLogo (contents/images/3840x2400.jpg). All three global themes
  set [Wallpaper] Image=SteamDeckLogo, the Plasma 6 way: it is the default for
  desktops without a wallpaper of their own, and it works from /usr/share or
  ~/.local/share. The org.kde.plasma.folder.js setup scripts that hardcoded
  /usr/share/wallpapers/... were removed from Vapor Deck and VGUI.
- VGUI.colors: error/warning/success text was plain white in every group. Now
  255,160,140 / 246,204,96 / 165,222,120 in Window, View, Button, Tooltip, Header
  and Complementary (contrast >= 3.8:1 on window, >= 5:1 on views). Selection
  keeps white, which reads best on the gold selection color.
- com.valve.vapor.desktop: now has the Vapor Deck splash (contents/splash),
  so applying plain Vapor sets the Steam Deck logo splash instead of keeping
  whatever splash was there.
- VGUI.colors [Colors:Header][Inactive]: was untouched Breeze Dark (grey 42,46,50,
  blue accents), so unfocused KDE app toolbars turned grey. Now the same olive
  values as [Colors:Header], matching VGUI's title bars (same olive focused or not).
- Removed icons/hicolor/scalable/places/distributor-logo.svg (a symlink to
